# Ручной сбор: цены и трассы

Папка для данных, собранных руками. У каждого файла рядом лежит
мета-файл .meta.json с родословной цифр: источник, дата сбора, решения.

## prices_season_2026_27.csv - цены ски-пассов

Сезонный срез: одна строка на курорт, 29 из 32 с ценой. Файл подключен
в конвейер: витрина берет цены прямо из него (без промежуточной
таблицы), правки сразу влияют на рейтинг - после правок пересобрать
(`python src/run_all.py`).

## trails_options_2026_27.csv - трассы

Информация с официальных сайтов курортов и агрегаторов о количестве,
сложности и длине трасс, перепаде высот, возможности фрирайда
и катания на тюбинге. Одна строка = курорт.

Файл подключен в конвейер: скрипт build_trails_options.py собирает
из него таблицу data/prepared/resort_trails_options.csv, она питает
сценарные баллы - цвета трасс, перепад, тюбинг, фрирайд. Базовый
рейтинг использует километраж трасс из OSM, а не этот файл. После
правок - `python src/run_all.py`.
